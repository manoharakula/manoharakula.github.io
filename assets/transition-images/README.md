# Transition Image Asset Manifest

These assets are intended for the Apple-inspired supply chain portfolio scroll transitions. The downloaded web images come from Wikimedia Commons pages with public-domain or CC0 licensing where possible. The SVG files are original generated-by-Codex assets for sections where photos would be less effective.

## Recommended Usage

| File | Use in portfolio | Motion idea |
|---|---|---|
| `port-singapore-wide.jpg` | Hero / global supply chain scale | Slow zoom-out with pinned headline |
| `container-grid-topdown.jpg` | Precision, routing, and logistics network section | Horizontal parallax or mask reveal |
| `port-elizabeth-containers.jpg` | Freight movement and operational complexity | Fade from muted grayscale to color |
| `container-ship-terminal.jpg` | Large-scale logistics and shipping section | Pinned image with copy sliding over left side |
| `warehouse-asrs-automation.jpg` | Apple-fit / automation and operations section | Vertical pan with reveal copy |
| `supply-warehouse-operations.jpg` | Optional operational execution / people-and-process section | Subtle scale-in and text fade |
| `supply-chain-data-map.svg` | Data engineering, lineage, and cloud migration section | Animate line opacity / node reveal in CSS |
| `forecasting-signal-grid.svg` | Forecasting, AI, and predictive analytics section | Animate chart line stroke and metric cards |

## Public Portfolio Guardrails

- Do not use Apple product images, Apple logo marks, or Apple page screenshots.
- Use these assets as supply-chain context, not as claims of direct Apple affiliation.
- Pair each visual with Manohar's actual supply chain analytics work: forecasting, freight audit, cloud migration, dashboard conversion, AI chatbots, and operational visibility.
